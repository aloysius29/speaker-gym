# Xlo.builds — Speaking Practice Website

A lightweight static website for English-speaking practice. It works locally in a browser and can be hosted for free with GitHub Pages or Netlify.

## Features
-  Spin the wheel to discover random topics.
-  Explore diverse categories, including technology, sports, movies, science, and personal development.
-  Customized topics covering interests like Formula 1, Cristiano Ronaldo, superheroes, cars, and more.
-  Quick Start and Deep Dive modes with adjustable timers.
-  Research, prepare, and speak on topics to build confidence.
-  Simple, responsive interface for desktop and mobile.

## Customise topics
Open `topics.js`. It contains the complete topic bank as an array of `[category, prompt]` pairs. Add new pairs using the same format.
